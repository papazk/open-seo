SEO Portfolio Local

SEO Portfolio Local is a private website-management workspace operated by Kiril Papaz. It brings together the SEO Portfolio dashboard and a self-hosted OpenSEO installation for reviewing websites that the operator manages.

The dashboards show Google Search Console search performance, connect verified website properties to individual projects, and help investigate search visibility and indexing. Website project notes and saved reports support the operator's SEO planning.

Why the app connects to Google

With your permission, the app reads Search Console data for properties your Google account can access. This includes property names, permission levels, search queries, pages, clicks, impressions, click-through rates, average positions, and available URL-inspection results. OpenSEO also uses basic Google identity information to identify the connected account.

The Search Console connection is read-only. It does not change your website, submit changes to Google, or request Gmail, Drive, or payment access. Google Analytics requires a separate authorization if that feature is enabled later.

The public information pages explain the application. Access to the actual dashboards is restricted to authorized users.
